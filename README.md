# Ascension Frontend

Public website source for Ascension Experience Society.

## Local Commands

```bash
pnpm install
pnpm dev
pnpm build
```

The frontend is configured to communicate with the local/private CMS through environment variables in `apps/website/.env.example`.

Default local endpoints:

- Website: `http://127.0.0.1:5173`
- CMS: `http://127.0.0.1:5174`
